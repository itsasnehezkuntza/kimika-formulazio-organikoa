# KIMIKA · 2. BATXILERGOA / 2.º BACHILLERATO

Web educativa interactiva de Química para 2.º de Bachillerato (en euskera y castellano).

## Contenidos

- **Atomoak eta Loturak / Átomos y Enlaces:**
  - Teoría cuántica, números cuánticos y configuración electrónica.
  - Tabla periódica, apantallamiento y carga nuclear efectiva ($Z^*$).
  - Propiedades periódicas: radio atómico e iónico, energía de ionización, afinidad electrónica y electronegatividad.
  - Enlace químico, propiedades de sólidos, estructuras de Lewis, geometría molecular (RPECV / BGEBAT), polaridad y fuerzas intermoleculares.
- **Kimika Organikoa / Química Orgánica:**
  - Formulación y nomenclatura orgánica, grupos funcionales, prioridades y guías paso a paso.
- **Ariketak / Ejercicios:**
  - Práctica interactiva por niveles con corrección inmediata y pistas.

## Privacidad y datos

El progreso y las preferencias de idioma se guardan localmente en el navegador del alumno (`localStorage`). No hay cuentas de usuario ni recogida de datos.
